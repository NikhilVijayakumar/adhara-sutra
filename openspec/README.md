# OpenSpec

Requirements are indexed in [docs/requirements](../docs/requirements/README.md),
and durable context is in [knowledge](../knowledge/index.md). Changes under
`changes/` contain proposed specifications. `specs/` holds accepted baseline
specifications after their changes are reviewed and archived; none are accepted
yet. Drafts do not establish an implementation or settle open decisions.

Completed, rescoped review: [architecture-integrity-review](changes/architecture-integrity-review/proposal.md),
with [evidence](changes/architecture-integrity-review/evidence.md). Its source remains
in place pending official OpenSpec validation and archival. The remaining conditional
and optional work is tracked in the active [integration workflows follow-up](changes/integration-workflows-followup/proposal.md).

Use the installed OpenSpec CLI to create and validate changes. Review source
requirements and resolve conflicts before approving or implementing a change.
